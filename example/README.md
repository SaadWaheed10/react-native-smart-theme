# Smart Theme — Expo example

```bash
npm install
npm start
```

Uses the local package via `file:..` and Metro `watchFolders`.

### Notes

- `smartAdapt="ask"` — toggling appearance shows **Theme only** vs **Apply overall**
- Persistence uses memory unless you install MMKV / AsyncStorage
- Animations are off in the demo (no Reanimated required)

Optional:

```bash
npx expo install react-native-reanimated react-native-mmkv
```
